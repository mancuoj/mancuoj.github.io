CS61A 这个坑拖了整整三年。23 年开了个头，中间断断续续，直到 26 年过完年后才真正捡起来，6 月总算是全部刷完了。

说实话，学得挺功利的。视频基本没动，教材也就随便翻了翻，拿到题目直接上手，纯粹奔着通过测试去。因为 Python 语法比较熟，倒没怎么卡住，几个 Project 更多是在考验读文档和理解逻辑的能力。

整体收获没有想象中那么大，也谈不上什么“世界观被重塑”，大部分内容只是把以前接触过的知识重新过了一遍。硬要说的话，对递归的理解确实比以前更透彻了一些。

卡得最久的是 Scheme 那部分，尤其是最后的 Interpreter 项目。虽然自己写的代码量不算大，但得硬着头皮去读大量的框架代码。我平时最烦的就是读别人的代码和 debug，最后全凭一口气啃完，写完那一刻心里只有一句话：“总算是结束了”。

至于这门课值不值得刷？我觉得是值得的，但真没必要神化。像我这种刷法收益很有限，如果愿意静下心来认真看视频、读教材，收获肯定会比我大得多。
